# Find a Part

Nuxt 4 + Supabase starter MVP for a global automotive parts marketplace.

## Included
- Public landing page and marketplace search
- Part detail page
- Supplier dashboard and inventory pages
- Add-part form
- Repairer dashboard
- Wanted-part request form
- Admin dashboard starter
- Supabase/Postgres schema
- Dark automotive visual theme

## Run locally
1. Copy `.env.example` to `.env`
2. Add your Supabase URL and anon key
3. Run `npm install`
4. Run `npm run dev`
5. Run `supabase/schema.sql` in the Supabase SQL Editor
